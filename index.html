Why these fields matter
Process archetype

Controls how the six scoring criteria are weighted. For example, geography carries more weight for energy than for generic manufacturing. Choosing the wrong archetype can change the score and ranking even when the selected dataset itself is correct.

Geography

Defines the target location against which Ecoinvent geography is assessed. Enter the geography of the real process, not the geography of the dataset you want to test.

Reference unit

Checks whether the dataset can represent the same quantified function. Enter the unit required by your model. A categorical incompatibility, such as kg versus kWh, can block the assessment.

Dataset purpose

Defines the modelling role you actually need. Select transformation when modelling a physical production step and market when modelling supply. A role mismatch can block an otherwise similar dataset.

i How to read these results

Dataset Fit Score - Measures how well the selected dataset represents the real process described. Higher is better.

Assessment Confidence - Indicates how reliable the assessment is based on the completeness of the process description and the Ecoinvent metadata available.

Selection Robustness - Shows the gap from the strongest valid alternative. A value close to 0 means the selection is robust; a negative value means a stronger alternative exists.

Overall label - Summarizes the Fit Score, unless a critical compatibility rule overrides it.
